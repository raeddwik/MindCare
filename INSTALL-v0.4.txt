- Do NOT use a service_role or secret key.

index.html:

<script src="./supabase.js"></script>

Keep:
<script src="./app.js"></script>

Then commit/push:
1. app.js
2. supabase.js
3. index.html

The new app:
- reads therapists/services/availability from Supabase
- writes confirmed bookings to public.appointments
- uses the database-generated MC-XXXXXXXX booking code
- relies on the database validation and overlap protection
- keeps only the customer's own recent booking references in localStorage for the current device

Admin management remains intentionally disabled until authentication + admin/therapist RLS policies are implemented.
